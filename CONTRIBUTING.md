# Contributing

Thanks for looking. Where things stand:

- **Issues are welcome**: bug reports (with the output of `dropviz --version` and your OS), questions, and ideas.
  A small repo to reproduce a problem helps a lot; `examples/make_demo_repo.py` builds a synthetic one.
- **Code contributions are not accepted yet.** Pull requests will be closed without review for now.
  This will be revisited once the project has settled; the decision will be written here.
- Please do not paste private repository contents, transcripts or tokens into issues. Token counts are fine.

Running the tests: `python3 -m unittest discover -s tests` (Python 3.10+, standard library only).
